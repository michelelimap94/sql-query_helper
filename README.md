# SQL Query Helper

Ferramenta web interativa para estudo e prática de SQL, com exemplos de consultas, tabelas e exercícios baseados em cenários genéricos de dados.

## O que o projeto demonstra

- Construção de consultas SQL passo a passo
- SELECT, FROM, WHERE, GROUP BY, ORDER BY e LIMIT
- Funções de agregação como COUNT, COUNT DISTINCT, SUM e AVG
- Organização de consultas para análise de dados
- Interface web com HTML, CSS e JavaScript
- Uso de dados e cenários fictícios para demonstração

## Tecnologias

HTML5 • CSS3 • JavaScript

## Como usar

Abra o arquivo `index.html` no navegador ou publique o repositório com GitHub Pages.

> Projeto desenvolvido para estudo e portfólio. Os exemplos e estruturas de dados são fictícios e genéricos.
