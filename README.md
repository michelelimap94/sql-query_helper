## Sobre o projeto

O **SQL Query Helper** foi criado como um projeto de estudo e portfólio para transformar a prática de SQL em uma experiência mais visual e organizada.

A ferramenta permite montar consultas por etapas, explorar exemplos prontos e revisar conceitos fundamentais usados em análises de dados.

O projeto utiliza **cenários e estruturas de dados fictícios**, sem informações de empresas, clientes ou bases reais.

## O que é possível praticar

- Montagem de consultas SQL passo a passo
- \`SELECT\` e \`FROM\`
- Filtros com \`WHERE\`
- Agrupamentos com \`GROUP BY\`
- Ordenação com \`ORDER BY\`
- Limitação de resultados com \`LIMIT\`
- Funções de agregação:
  - \`COUNT\`
  - \`COUNT DISTINCT\`
  - \`SUM\`
  - \`AVG\`
- Consultas voltadas para cenários de clientes, pedidos, produtos, pagamentos e campanhas
- Organização do raciocínio necessário para transformar uma pergunta de negócio em uma consulta SQL

## Exemplos de análise

A ferramenta traz exemplos como:

**Clientes por cidade**
> Quantos clientes existem em cada cidade?

**Vendas por período**
> Qual foi o total de vendas em determinado período?

**Produtos mais vendidos**
> Quais produtos tiveram maior quantidade de vendas?

**Resultados de campanhas**
> Como comparar os resultados de diferentes campanhas?

Esses exemplos ajudam a conectar a **sintaxe SQL** com perguntas comuns de análise de dados.
